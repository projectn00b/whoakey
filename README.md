## What Whoakey is

Whoakey is a social events platform built around QR codes.

**Live today** is a free QR code marketing tool. No login is required to start:

- **Generate** a QR code for any promotion URL
- **Scan** a QR code with your device camera, right in the browser
- **Open** a QR code from an image or code you already have
- **Save, share, and print** the codes you make

**In development** on top of that is the full social events product:

- Plan an event and publish it behind a QR code
- A public wall for each QR code and event, with comments and feedback
- Guest lists, staff lists, co-hosts, and invites
- Event schedules, locations, and maps
- Profiles, friends, and direct messages between users
- Star ratings and feedback on events
- Video chat for events, built on WebRTC

## Tech stack

- **Framework:** Nuxt 3 and Vue 3
- **Language:** JavaScript
- **Server:** Node.js
- **Database:** Postgres
- **Video:** WebRTC
- **Hosting:** Vercel, with the video server on Render

## Project status

Whoakey is live at [whoakey.com](https://www.whoakey.com) as a free QR code
generator, scanner, and opener. The social events features are in active
development.

This repository is the public project overview. The application source code
is kept in private repositories and is not included here.
